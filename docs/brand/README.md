# JokiBlox logo

**Mark:** a J built from Roblox-style blocks, with the AI spark sitting where the next block goes — the agent that builds your game block by block.

| File | Use |
|---|---|
| `jokiblox-mark-black.svg` / `jokiblox-mark-white.svg` | The mark on light / dark backgrounds |
| `jokiblox-app-icon.svg`, `jokiblox-app-icon-512.png` | App icon, Discord bot avatar, social profile |
| `jokiblox-logo-sheet.png` | Overview: lockup, colours, small sizes |
| `alt-squad-pinwheel.svg` | Alternate idea (four agents around the spark), not in use |

**Rules**
- One colour only: white on dark, `#0b0c0d` on light, or white on brand green `#00b06f`.
- Lockup: mark + "JokiBlox" in Montserrat Black; "AGENT" small caps underneath (optional).
- Clear space around the mark = the spark's width. Minimum size 16 px.
- Don't tilt it — a tilted square is Roblox's logo; we stay upright to keep clear of it.
- On the site the spark pops in on load, twinkles every few seconds and spins on hover (`.jb-mark`).
