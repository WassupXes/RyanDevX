## Weaker signals (not on the homepage yet)
- **Hiring is unreliable** — Talent Hub posts going unanswered, pay disputes. Evidence is thin ([Talent Hub tag](https://devforum.roblox.com/tag/talent-hub)); could become a "your on-call dev squad" angle for the Indonesian market (the "joki" idea) after we validate it with waitlist answers.
- **Live-game visibility** — no way to watch live servers from Studio ([Live server editing request](https://devforum.roblox.com/t/live-server-editing/103025)); supports the Discord traffic/error alerts.

## Competitive context
Roblox's own Assistant now connects to Claude/OpenAI/Gemini (BYOK) and Studio has a built-in MCP server, so "AI in Studio" alone is not a differentiator. JokiBlox's edge must be the items above: reliability checks (2), control and undo (3), QA agent (4), security (5) and anti-exploit (5b), multi-agent squad (6), pre-checks (7), migration (8), plus Discord, Bahasa Indonesia and local payments.
